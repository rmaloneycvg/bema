# Bema Study Guide Generator and Truncated Transcripts

bema-study-guide-agent.json  is an agent run with kiro-cli that can run multithreaded in batches of 16 episodes at once.  It generates a study guide with consistent through-lines derived from all bema episodes across 5 seasons linking all relavent context and diagraming every chiasm.  Read the agent description and prompt for a full understanding of what this agent creates.  through-lines.md is updated as study guides are generated.
