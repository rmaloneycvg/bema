# BEMA Session 1 — Recurring Through-lines Registry

This registry is the single source of truth for the recurring motifs ("through-lines") that run across the regenerated Session 1 per-episode study guides (episodes 1-0 through 1-32). It is rebuilt entirely from the **Recurring Through-lines** section of each of the 33 guides — no motif is assumed or imported from outside those guides. Its purpose is to let a reader or facilitator trace any one motif across the whole session: where it is anchored, where it recurs, and whether each appearance is an explicit host-named thread or a genuinely-implied one. When the per-episode guides and this registry disagree, the per-episode guides win and this file should be rebuilt.

## Entry format and link convention

Each entry below records one motif and has:

- **Motif name** (as the `###` heading) and a one-line description.
- **Anchor:** the earliest / defining episode for that motif, as a markdown link.
- **Appears in:** every episode whose guide engages the motif, in episode order (0, 1, 2, …, 32), each as a markdown link.
- **Notes:** (optional) cross-references, nuances, or forward pointers.

Every episode is written as a link to its study guide in this same folder, in the form `[<basename>](./<basename>.md)` — e.g. [1-3-master-the-beast.md](./1-3-master-the-beast.md). All 33 guides are present, so the `./<basename>.md` form is always used. Each appearance is tagged **(explicit)** when the source guide named/cited the motif outright, or **(implied)** when the source guide recorded it as genuinely-implied / set-up rather than named. A short parenthetical note is added per link where it helps.

## Association policy

Explicit beats implied beats never-force. A motif is listed for an episode only when that episode's guide genuinely engaged it: first on the strength of an explicit host citation, otherwise on a genuinely-implied thread the guide itself recorded. Motifs are never forced onto an episode whose guide declined them (several guides explicitly note motifs they did **not** claim — those non-claims are honored here by omission). No motif appears that no guide records.
