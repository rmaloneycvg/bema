# BEMA Sessions 1–2 — Recurring Through-lines Registry

This registry is the single source of truth for the recurring motifs ("through-lines") that run across the regenerated per-episode study guides for **Session 1 (episodes 1-0 … 1-32)** and **Session 2 (episodes 2-34 … 2-71)**. It is built from the **Recurring Through-lines** section of each guide — and, for the Session 2 guides that recorded their motifs under *Key Lessons*, *East/West Lens*, or *Callbacks & Foreshadowing* instead, from those sections — so that no motif is assumed or imported from outside the guides themselves. Its purpose is to let a reader or facilitator trace any one motif across both sessions: where it is anchored, where it recurs, and whether each appearance is an explicit host-named thread or a genuinely-implied one. When the per-episode guides and this registry disagree, the per-episode guides win.

## Entry format and link convention

Each entry below records one motif and has:

- **Motif name** (as the `###` heading) and a one-line description.
- **Anchor:** the earliest / defining episode for that motif, as a markdown link.
- **Appears in:** every episode whose guide engages the motif, in episode order (Session 1 first — 0, 1, 2, …, 32 — then Session 2 — 34, 35, …, 71), each as a markdown link.
- **Notes:** (optional) cross-references, nuances, or forward pointers.

Every episode is written as a link to its study guide in this same folder, in the form `[<basename>](./<basename>.md)` — e.g. [1-03-master-the-beast.md](./1-03-master-the-beast.md) or [2-49-hosea-garden.md](./2-49-hosea-garden.md). All guides are present, so the `./<basename>.md` form is always used. Each appearance is tagged **(explicit)** when the source guide named/cited the motif outright, or **(implied)** when the source guide recorded it as genuinely-implied / set-up rather than named. A short parenthetical note is added per link where it helps.

## Association policy

Explicit beats implied beats never-force. A motif is listed for an episode only when that episode's guide genuinely engaged it: first on the strength of an explicit host citation, otherwise on a genuinely-implied thread the guide itself recorded. Motifs are never forced onto an episode whose guide declines them; such non-claims are honored by omission.

### Right-handed vs. left-handed power
